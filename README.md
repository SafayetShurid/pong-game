# Pong Multiplayer

A classic Pong arcade game with local and online multiplayer support.

## Features
- 🎮 **Local Mode**: 2 players, 1 keyboard
- 🌐 **Online Multiplayer**: Play with friends on different devices
- 🔊 **Retro Sound Effects**: Synthesized arcade sounds
- ⚙️ **Customizable**: Winning score and ball speed settings

## Running Locally

```bash
npm install
npm start
```

Then open http://localhost:3000

## Online Multiplayer

1. Click "Online" mode
2. Host: Click "Create Room" and share the 4-letter code
3. Guest: Enter the room code and click "Join"
4. Host clicks "Start Game" when both players are connected

## Controls

**Local Mode:**
- Player 1: W / S
- Player 2: ↑ / ↓
- Pause: ESC or SPACE

**Online Mode:**
- W / S or ↑ / ↓ (controls your paddle)
